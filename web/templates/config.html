Конфигурация

Редактирование YAML-файлов ящиков. Изменения применяются без перезапуска.

Провайдер модели

Cloud.ru: ключ берётся только из переменной среды CLOUDRU_FOUNDATION_MODELS_API_KEY. Переключение провайдера возвращает ящик в Dry Run.
Как это работает: каждый файл в папке configs/ — отдельный почтовый ящик. После сохранения конфиг автоматически перечитывается. Обязательные секции: name, imap, llm, rules. Секреты скрыты как <REDACTED> при просмотре. Не меняйте этот маркер, если хотите сохранить текущее значение. Для нового секрета используйте ENV:ИМЯ_ПЕРЕМЕННОЙ.
Пояснения к полям:
imap.host / port — адрес и порт IMAP-сервера (обычно 993)
imap.username / password — логин и пароль (или ENV:VAR)
imap.inbox_folder — папка входящих (обычно INBOX)
imap.unsorted_folder — куда складывать письма с низкой уверенностью
imap.poll_interval_seconds — как часто опрашивать ящик (мин. 10)
llm.provider — ollama или cloudru
llm.endpoint — адрес Ollama (по умолчанию http://localhost:11434)
llm.base_url — Cloud.ru API (фиксированный HTTPS-адрес)
llm.api_key — только ENV:CLOUDRU_FOUNDATION_MODELS_API_KEY
llm.model — имя модели
llm.max_tokens — для Cloud.ru включает reasoning-токены; рекомендуется не менее 2048
llm.temperature — необязательно для Cloud.ru; зависит от модели
llm.system_prompt — формируется из правил автоматически
rules.confidence_threshold — порог уверенности (0–1)
rules.categories — список {name, folder}
web.admin_username / admin_password — логин/пароль веб-интерфейса
logging.* — уровень, файл, ротация
